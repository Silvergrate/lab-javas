## Завдання

Тема роботи — сучасні можливості Java та підхід Data-Oriented Programming.

Варіант визначається за остачею від ділення номера залікової книжки на 3:

`4104 mod 3 = 0`

Для варіанта 0 реалізовано обробку станів замовлення:

- `Pending` — очікування обробки;
- `Paid` — оплата з номером платежу та сумою;
- `Shipped` — відправлення з кодом відстеження та датою;
- `Cancelled` — скасування із зазначенням причини.

Стани описані записами `record`, які реалізують `sealed interface OrderStatus`. Метод `OrderProcessor.process()` обробляє їх через `switch` із pattern matching та повертає текстовий опис. Перевірки даних виконуються в конструкторах записів.

## Запуск в IntelliJ IDEA

Потрібен JDK 21 або новіший.

1. Відкрити `pom.xml` як проєкт через **File → Open**.
2. Дочекатися імпорту Maven та завантаження залежностей.
3. У **File → Project Structure → Project** вибрати встановлений JDK.
4. Відкрити `Main.java` у пакеті `ua.kpi.comsys.dop` і запустити метод `main` зеленою стрілкою.

Програма виводить приклади всіх чотирьох станів. Наприкінці показано перевірки некоректних даних: порожніх полів, нульової суми та `null`.

## Тестування

Тести написані на JUnit 5 і розташовані в `src/test/java`:

- `OrderStatusTest` перевіряє створення записів і відхилення некоректних значень;
- `OrderProcessorTest` перевіряє результати обробки станів, формат сум та обробку `null`.

Для запуску всіх тестів потрібно натиснути правою кнопкою на папку `src/test/java` та вибрати **Run Tests**.

Результат перевірки: усі 48 тестів пройшли успішно.
